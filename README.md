# Pinoy Prime Booking Services — Account Deletion Page

This folder contains `index.html` for a GitHub Pages site.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository, for example:
   `pinoy-prime-account-deletion`
2. Upload `index.html` to the repository root (not inside another folder).
3. Before publishing, edit `index.html` and replace the retention-period notice with the actual retention period approved by the developer.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. The public URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/pinoy-prime-account-deletion/`
8. Open the URL in a private/incognito browser window to confirm it is publicly accessible.

IMPORTANT:
- Do not submit the URL to Google Play until the retention period is completed and the actual deletion process has been verified.
- The page currently describes email-based requests. Make sure the team monitors `infopinoyprime@gmail.com` and can fulfill verified requests.
- Never ask users to email their password.
